# HiTerm

**中文** | [English](./README.md)

> 💻 一款易用、美观且功能丰富的 Shell 管理应用 — 由 [Guzyeah Studio](https://www.guzyeah.cn) 开发。

HiTerm 是一款基于 **Fluent UI** 构建的跨平台桌面终端应用，将本地与远程 Shell 管理统一于一个优雅的界面。

---

## ✨ 功能特性

### 🔌 多协议连接管理
| 协议 | 说明 |
|----------|------|
| **SSH** | 远程 Shell，支持密码 / 私钥认证 |
| **Local** | 内置系统终端 (`cmd`, `PowerShell`, `Git Bash`, `bash`, `zsh`, `sh`) |
| **Telnet** | 传统 telnet 连接 |
| **Serial** | 串口终端，支持波特率、校验位、流控制等配置 |
| **VNC** | 远程桌面访问 |
| **RDP** | 远程桌面协议 |

### 📂 连接分组管理
将连接按自定义分组组织。树形视图直观展示分组与连接，支持右键菜单删除分组（仅当分组为空时方可删除）。

### 🖥️ 终端
- 支持**字体**、**字号**和**字体连字**配置
- 多款内置终端主题（如 `Windows Console Dark`、`Solarized` 等）
- 终端视图模式：**普通**、**最大化**、**全屏**
- 每会话的命令历史记录与回放

### 📁 内置文件浏览器
本地与远程主机之间的双向文件传输：
- 浏览目录、查看文件元信息
- 上传 / 下载文件与文件夹，支持进度显示
- 创建、删除、重命名文件和目录
- 同时支持本地和 SSH 远程文件系统

### 📊 系统资源监控（状态栏）
底部状态栏实时显示系统指标：
- **CPU** 使用率（含迷你趋势图）
- **内存** 使用率
- **网络** 上传 / 下载速率
- **磁盘** 读取 / 写入速率与总使用率
- 所有指标每 2 秒更新一次

### 📜 命令历史
每会话独立的命令历史记录，支持：
- 搜索与筛选
- 复制命令到剪贴板
- 重新运行历史命令
- 删除单条记录

### 🗂️ 标签页工作区
- 多标签页终端工作区
- 标签栏支持左侧 / 顶部停靠
- 每个标签页拥有独立的终端会话

### 🎨 Fluent Design 界面
- 完全使用 [Fluent UI React Components](https://react.fluentui.dev/) 构建
- 支持**浅色** / **深色** / **跟随系统** 主题
- 细腻的动画与平滑过渡
- 无障碍访问与键盘友好
